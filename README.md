# Lab-Movie-Rating-System
1. **How does a nested if differ from an if-else statement?**\
    A nested `if` is an `if` statement placed inside another `if` statement, allowing you to check additional conditions. An `if-else` statement chooses between two different actions depending on whether a condition is true or false.
2. **What are the advantages of using switch over multiple if statements?**\
    A `switch` statement makes code easier to read and organize when checking one variable against several specific values. It can be cleaner and less repetitive than using multiple `if-else` statements.
3. **How does the conditional operator simplify decision-making?**\
    The conditional operator `? :` allows you to make a simple decision in one line of code. It checks a condition and returns one value if the condition is true and another value if it is false.
4. **What is short-circuit evaluation, and how does it affect the use of logical operators?**\
    Short-circuit evaluation means Java stops checking a logical expression as soon as it knows the final result. With `&&`, if the first condition is false, Java doesn't check the second condition; with `||`, if the first condition is true, Java doesn't check the second condition. This can make programs more efficient and prevent unnecessary operations.
